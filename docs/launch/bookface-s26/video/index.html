WorkOS over Auth0
decisionsauth updated 3 days ago · written from 4 sessions
SSO and SCIM go through WorkOS. Auth0 was prototyped in February and dropped — enterprise connections were priced per-connection, and SCIM required a separate add-on.
DECISION
Every identity provider goes through src/auth/workos.ts. Never call provider APIs directly from route handlers.

WorkOS webhook replay
gotchasauth from the Jun 3 debugging session
WorkOS retries webhook deliveries aggressively and does not dedupe — a provisioning event can arrive twice.
GOTCHA
Handlers must be idempotent. Use the event id as an idempotency key — this caused the June 3 double-provision incident.
